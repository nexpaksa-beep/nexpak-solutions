Alarm Relay Modules & Output Expansion

Understand alarm relays, programmable outputs and output expansion—and how they can connect an alarm system with sirens, strobes, gates, access control and other compatible security equipment.

South Africa Security Systems Guide

What Is an Alarm Relay Module?

An alarm relay module is an interface that allows a security alarm system to control another compatible electrical circuit. The alarm panel can activate an output, while the relay provides electrically isolated switching contacts for an external device where the equipment and specifications allow it.

Important: Relay ratings, voltages and wiring arrangements vary. Always follow the alarm-panel and relay manufacturer's specifications. Mains-voltage work should be handled by a suitably qualified professional.

Alarm Outputs Explained

Modern alarm panels can provide different types of outputs. Some are designed for dedicated functions, while programmable outputs—often called PGM outputs—can be assigned to supported events or automation functions.

PGM / Programmable Output

A configurable alarm-panel output that can respond to supported events such as arming, alarm conditions or other programmed states.

Relay Output

A relay provides switching contacts, commonly described as COM, NO and NC, allowing a compatible external circuit to be controlled.

NO, NC and COM Contacts

Relay terminology describes the state of the relay contacts. COM is the common contact. NO means normally open and NC means normally closed. Which contact arrangement is appropriate depends on the equipment being controlled and the intended fail-safe behaviour.

Where Alarm Outputs Can Be Used

Sirens & Strobes

Compatible output interfaces can be used to control audible or visual warning equipment according to the alarm system design.

Gate & Access Control

Alarm events can sometimes be integrated with compatible gate or access-control equipment through an approved interface.

Lighting

A suitable interface may allow an alarm event to trigger compatible security lighting or an automation controller.

Security Automation

Output expansion can provide additional control functions where supported by the alarm panel and connected equipment.

Safe Output Expansion Planning

  • Check the alarm panel's supported output types and maximum ratings.
  • Confirm the voltage and current requirements of the device being controlled.
  • Use an appropriate interface or relay where direct connection is not supported.
  • Consider isolation between the alarm panel and external equipment.
  • Document output assignments and labels for future servicing.
  • Keep low-voltage security wiring separated from mains wiring as required by applicable standards.
  • Test the complete system after installation without defeating security protections.

Common Alarm Relay & Output Problems

Output does not activate

Check programming, event assignment, panel status, power and compatibility. Do not assume that every PGM output can directly drive every external device.

Relay chatters or behaves intermittently

Possible causes include unsuitable load characteristics, unstable power, incorrect configuration or a relay/interface that is not appropriate for the application. Have the installation checked rather than repeatedly cycling the equipment.

External device does not respond

Confirm that the external device accepts the switching method being provided and that its power supply is independent where required.

Frequently Asked Questions

Can an alarm relay control a gate motor?

It can be possible when the alarm system and gate controller support a compatible input and an appropriate interface is used. The gate controller manufacturer's requirements should always be followed.

What is a PGM output on an alarm panel?

A PGM is generally a programmable output that can be assigned to supported functions or events. Its electrical characteristics vary between alarm-panel models.

Can I connect mains power directly to an alarm panel output?

No. Never assume an alarm output is suitable for mains voltage. Use an appropriate certified interface and qualified electrical installation where mains switching is involved.

Does a relay add more alarm zones?

No. A relay/output module expands or interfaces outputs. A zone expander is used to increase compatible alarm inputs.
