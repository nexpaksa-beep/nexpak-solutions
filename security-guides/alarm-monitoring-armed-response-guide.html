What Is Alarm Monitoring?

Alarm monitoring connects a security alarm system to a person, monitoring centre or other designated receiving service. When a qualifying event occurs, the alarm system communicates information about the event so that it can be assessed and handled according to the agreed response procedure.

A monitored alarm is therefore more than a siren on the property. The security system can become part of a wider response process involving sensors, an alarm control panel, a communication path, a monitoring operation and, where contracted, a response service.

Important: Monitoring and armed response are related but not identical. Monitoring is the communication and assessment service; armed response is a separate physical response service governed by a provider's coverage, procedures and contract.

How a Monitored Alarm System Works

1. Sensor detects an event

A PIR, magnetic contact, panic button, smoke detector or other connected device can generate an alarm event.

2. Panel processes it

The alarm control panel evaluates the zone or device and activates programmed outputs and communications.

3. Signal is transmitted

The system sends the event through its available communication path, such as cellular or IP-based communication.

4. Event is received

A monitoring operation receives the event and applies its verification and escalation procedure.

5. Contact or verification

Depending on the service, designated contacts may be notified and additional verification may be performed.

6. Response process

Where an armed-response service applies, a response may be dispatched according to the contract and operating conditions.

What Does a Monitoring Centre Do?

A monitoring centre is designed to receive security events and follow predefined procedures. Depending on the service, those procedures can include event verification, contacting nominated keyholders, escalating qualifying incidents and coordinating with the contracted response provider.

Typical information handled

  • Property or account identification.
  • Alarm zone or device that generated the event.
  • Event type, such as intrusion, panic or tamper.
  • Time and sequence of received events.
  • Relevant user or keyholder information.
  • Instructions and escalation rules defined by the service agreement.

Good monitoring depends on accurate account information. If phone numbers, keyholders, access instructions or other important details change, they should be updated with the relevant service provider.

What Is Armed Response?

Armed response is a security service where a contracted response provider may send trained personnel to a property after qualifying alarm events. The exact process differs between providers and contracts, so customers should understand what is included before signing up.

Alarm Communication: GSM, Cellular and IP

The communication path is one of the most important parts of a monitored alarm. If an alarm occurs but the communication path cannot deliver the event, the monitoring process can be affected.

GSM and cellular communication

GSM or cellular alarm communicators use a compatible mobile network to transmit events. They are useful where a traditional fixed telephone line is unavailable and can be especially valuable for sites where cellular coverage is reliable.

IP communication

IP-based communication can use an internet connection to transmit alarm events. It can provide useful connectivity but should be designed with network reliability and backup communication in mind.

Dual-path communication

Some security systems can use more than one communication route. A suitable dual-path design can reduce dependence on a single connection, although every backup path has its own availability requirements.

Backup Power and Alarm Reliability

Most professionally designed alarm systems include standby battery capacity so essential functions can continue during a mains power interruption. Battery condition matters: an old or degraded battery can reduce the period for which the system remains operational.

  • Keep the alarm panel and communication equipment supplied from the intended power source.
  • Have backup batteries inspected as part of routine servicing.
  • Investigate repeated low-battery warnings rather than repeatedly resetting them.
  • Consider communication redundancy for properties where uninterrupted reporting is particularly important.

For related technical information, see the alarm control panel guide.

Panic Buttons and Emergency Signals

Panic buttons provide a deliberate way for an authorised person to generate an alarm event. They can be fixed or wireless and may be positioned in locations where a person could need to raise an alert quickly.

Depending on the alarm and monitoring configuration, a panic event can be treated differently from a normal intrusion zone. Customers should understand how panic signals are classified and what the monitoring and response procedure is.

See the Alarm Panic Buttons & Emergency Buttons Guide for more information.

Alarm Monitoring for Homes

Residential systems commonly combine perimeter protection and interior detection. Magnetic contacts can monitor selected doors and windows, while PIR motion sensors can protect internal areas. A monitored system can add a communication and response layer if the homeowner chooses that service.

For residential planning, read the Home Alarm Systems Guide and Magnetic Door & Window Alarm Sensors Guide.

Alarm Monitoring for Businesses

Businesses may require more zones, user management, multiple access points and different security procedures. Monitoring can be integrated with access control, CCTV and other security technologies to provide a broader security strategy.

Read the Business Alarm Systems Guide for more planning considerations.

Farms and Remote Properties

Large or remote properties can present additional communication and response challenges. Long distances, variable cellular coverage, power interruptions and multiple buildings should be considered during system design.

A site assessment can help determine suitable sensor placement, communication options, power backup and the practical response process.

False Alarms and Nuisance Events

Repeated false alarms can disrupt occupants, neighbours, monitoring operations and response services. They can also indicate a technical or environmental problem.

Common causes

  • Incorrectly positioned or poorly secured sensors.
  • Unstable doors or windows triggering magnetic contacts.
  • Environmental conditions affecting motion sensors.
  • Low or unstable power supply.
  • Worn batteries in wireless devices.
  • Incorrect user operation or forgotten arming states.
  • Animals or other movement in protected areas.

Do not simply disable a troublesome zone indefinitely. A qualified installer should identify the cause and correct the underlying problem.

How to Choose an Alarm Monitoring Solution

  1. Start with the property. Identify doors, windows, internal areas, perimeter risks and important access points.
  2. Choose appropriate detection. Use PIRs, magnetic contacts, panic buttons and other devices according to the risk.
  3. Plan communications. Consider cellular, IP or another suitable reporting method and whether redundancy is needed.
  4. Plan power backup. Ensure the panel and communications equipment are appropriately supported during power interruptions.
  5. Understand the monitoring service. Ask exactly how events are handled and verified.
  6. Check response coverage. Confirm whether armed response is available at the property's location and what the service agreement says.
  7. Maintain the system. Test the system through the provider's approved procedure and service it periodically.

Frequently Asked Questions

What is alarm monitoring?

Alarm monitoring is the process of receiving security events from an alarm system and handling them according to a defined monitoring and escalation procedure.

What is armed response?

Armed response is a contracted physical security response service that may attend qualifying alarm events, subject to the provider's coverage and service agreement.

Can a GSM alarm system be monitored?

Yes. A cellular-enabled alarm communicator can send alarm events over a mobile network when properly configured and when suitable network coverage is available.

Does monitoring guarantee a security outcome?

No. Monitoring and response services reduce response delays and add a security layer, but no system can guarantee an outcome. Communication, operating conditions and service procedures all matter.

Why is backup power important?

Backup power can help the alarm and communications equipment continue operating during a mains power interruption, provided the battery and system are properly maintained.
